# dotfiles

Mes fichiers de configuration pour neovim, tmux, vim et zsh.

## Contenu
- nvim/ - Configuration Neovim
- tmux/ - Configuration Tmux
- zshrc/ - Configuration Zsh
- .vimrc - Configuration Vim

## Installation
Copier les dossiers dans `~/.config/` ou créer des liens symboliques :
```bash
ln -s ~/dotfiles/nvim ~/.config/nvim
ln -s ~/dotfiles/tmux ~/.config/tmux
```
